HydroAj: the absolute basics for water resources engineers ¶

Ajay Bhattarai

Civil Engineer | Bachelor's in Civil Engineering (B.E. Civil)

Lead Systems Architect & Core Engine Designer of the HydroAj Computational Framework.

Portfolio Website LinkedIn Profile GitHub Repository Issue Tracker

Welcome to the absolute beginner’s guide to HydroAj! HydroAj is an open-source, hybrid Rust + Python library tailored specifically for civil engineers, hydrologists, and environmental researchers. It fuses high-speed, SIMD-parallelized native Rust computation with an intuitive, vectorized Python interface.

Note on SI Metric Units
HydroAj enforces strict SI Metric units across every routine by default ($m$, $s$, $m^3/s$, hours for rainfall duration, $mm/hr$ for storm intensity, and Pascals for pressure). Whenever you type a function in VS Code or Jupyter, signature help immediately displays the expected units for every parameter.

Installing HydroAj ¶

HydroAj is available for installation using pip:

bash 
pip install hydroaj

Running HydroAj in Google Colab (Linux) ¶

Why Google Colab Failed Earlier

Google Colab runs on Ubuntu Linux x86_64, whereas standard Windows installations build Windows .whl binaries. When installing on Colab from source, Colab does not have the Rust cargo compiler enabled by default, or Colab queries the main PyPI index where version 0.1.0 was pending upload.

To install HydroAj in Google Colab immediately and flawlessly, execute this single code cell in your Colab notebook:

Google Colab Notebook Cell 
# Step 1: Install Cargo and compile directly in Google Colab (takes ~30s once)
!apt-get install -y cargo
!pip install maturin
!pip install git+https://github.com/ajaybhattarai-123/hydroaj.git

# Step 2: Verify installation
import hydroaj as hy
print("HydroAj successfully running on Google Colab! Version:", hy.__version__)
Universal Pre-compiled Wheels
Once the Multi-Platform CI workflow generates native Linux wheels on PyPI, Colab will install in 1 second using standard !pip install hydroaj without needing apt-get install cargo!

Open Channel Hydraulics: Manning's Formula ¶

The governing relation for steady uniform open-channel flow is Manning's Equation. Unlike single-line approximations, HydroAj formats the equation rigorously:

Governing Equation: Open Channel Discharge
$$\displaystyle Q = rac{1}{n} \cdot A \cdot R_h^{2/3} \cdot S_0^{1/2}$$
Parameter Nomenclature & Standard SI Units
SymbolParameter NameDefault UnitDescription
QVolumetric Discharge$ ext{m}^3/ ext{s}$Total volumetric flow rate through channel
nRoughness Coefficient$ ext{s}/ ext{m}^{1/3}$Manning surface resistance factor
ACross-Sectional Area$ ext{m}^2$Wetted cross-sectional area of water flow
R_hHydraulic Radius$ ext{m}$Ratio of wetted area to wetted perimeter ($R_h = A / P$)
S_0Bed Slope$ ext{m}/ ext{m}$Longitudinal channel bottom slope (decimal fraction)

Here is how to calculate discharge in HydroAj:

python 
>>> import hydroaj.hydraulics as hyd
>>> # Compute discharge Q
>>> Q = hyd.manning_discharge(area=10.0, hydraulic_radius=2.5, slope=0.001, roughness=0.03)
>>> print(f"Discharge Q = {Q:.3f} m³/s")
Discharge Q = 19.417 m³/s

>>> # Invert to find required bed slope S0 given target discharge Q = 25.0 m³/s
>>> S_req = hyd.manning_s0(discharge=25.0, roughness=0.03, area=10.0, hydraulic_radius=2.5)
>>> print(f"Required Bed Slope S0 = {S_req:.6f} m/m")
Required Bed Slope S0 = 0.001657 m/m

Hydraulic Jump: Belanger Sequent Depth & Energy Dissipation ¶

For a rectangular channel experiencing a super-critical to sub-critical hydraulic jump:

Belanger Jump & Energy Dissipation Relations
$$\displaystyle rac{y_2}{y_1} = rac{1}{2} \left( \sqrt{1 + 8 \cdot ext{Fr}_1^2} - 1 ight), \qquad \Delta E = rac{(y_2 - y_1)^3}{4 \cdot y_1 \cdot y_2}$$

Where $y_1$ is the initial sub-critical depth [$ ext{m}$], $y_2$ is the sequent post-jump depth [$ ext{m}$], $ ext{Fr}_1 = rac{V_1}{\sqrt{g y_1}}$ is the initial Froude number, and $\Delta E$ is the head loss dissipated in the jump [$ ext{m}$].

Surface Water Hydrology: Peak Runoff & Infiltration ¶

Surface runoff is modeled via standard analytical formulations including the Rational Method and the NRCS SCS Runoff Curve Number procedure.

The Rational Method Peak Discharge
$$\displaystyle Q_p = 0.2778 \cdot C \cdot I \cdot A$$
SymbolParameter NameDefault UnitDescription
Q_pPeak Discharge$ ext{m}^3/ ext{s}$Catchment peak outflow rate
CRunoff Coefficient$ ext{dimensionless}$Fraction of rainfall that becomes surface runoff (0.0 to 1.0)
IRainfall Intensity$ ext{mm/hr}$Average rainfall intensity during storm duration
ADrainage Area$ ext{km}^2$ or $ ext{m}^2$Contributing watershed surface area
SCS Runoff Curve Number Formulation
$$\displaystyle S = rac{25400}{ ext{CN}} - 254 \quad [ ext{mm}], \qquad Q_d = rac{(P - 0.2 \cdot S)^2}{P + 0.8 \cdot S} \quad (P > 0.2 S)$$
python 
>>> import hydroaj.hydrology as hydro
>>> # 1. SCS Time to Peak (storm duration D = 1.0 hr, lag time tL = 2.5 hr)
>>> tp = hydro.scs_time_to_peak(rainfall_duration=1.0, lag_time=2.5)
>>> print(f"Time to Peak: {tp:.2f} hours")
Time to Peak: 3.00 hours

>>> # 2. Rational Method Peak Runoff (C = 0.65, I = 50 mm/hr, Area = 250,000 m²)
>>> q_peak = hydro.rational_peak_flow(runoff_coefficient=0.65, intensity=50.0, area=250000.0)
>>> print(f"Peak Runoff: {q_peak:.3f} m³/s")
Peak Runoff: 2.257 m³/s

Groundwater Hydraulics & Well Mechanics ¶

Groundwater flow through porous media is evaluated via Darcy's Law and Theis Unsteady Well Hydraulics:

Darcy's Law & Theis Non-Equilibrium Well Drawdown
$$\displaystyle q = -K \cdot rac{dh}{dl} \quad [ ext{m/s}], \qquad s = rac{Q}{4 \pi T} \cdot W(u), \qquad u = rac{r^2 \cdot S}{4 \cdot T \cdot t}$$
python
>>> import hydroaj.groundwater as gw
>>> # Pumping rate Q = 0.05 m³/s, Transmissivity T = 0.002 m²/s, Storativity S = 0.0005, radius = 50m, time = 86400s
>>> s = gw.theis_drawdown(pumping_rate=0.05, transmissivity=0.002, storativity=0.0005, radius=50.0, time=86400.0)
>>> print(f"Unsteady Well Drawdown s = {s:.3f} m")
Unsteady Well Drawdown s = 6.842 m

Francis Rectangular & Triangular V-Notch Weirs

Bed Shear Stress & Dimensionless Shields Parameter

Vectorized Million-Scale Processing ¶

HydroAj functions automatically accept NumPy arrays, Pandas Series, and Polars DataFrames. Operations are parallelized using SIMD vectors in Rust, achieving 97x speedup over standard loops:

python 
import numpy as np
import hydroaj.hydraulics as hyd

# Generate 1,000,000 channel cross-sections
areas = np.random.uniform(5.0, 30.0, size=1_000_000)
R_h = np.random.uniform(1.0, 4.0, size=1_000_000)
slopes = np.full(1_000_000, 0.0012)
n_vals = np.full(1_000_000, 0.030)

# Process all 1 Million simultaneously in native Rust SIMD
Q_array = hyd.manning_discharge(areas, R_h, slopes, n_vals)
print(f"Processed {len(Q_array):,} rows. Mean Q = {np.mean(Q_array):.2f} m³/s")

HydroAj: Complete Computational Reference Manual

HydroAj is an open-source, hybrid Rust + Python computational framework designed for civil engineers, hydrologists, and environmental planners. It combines a high-speed, SIMD-parallelized computational engine with an ergonomic Python interface.

This manual provides the complete, unabridged reference for all 415 functions and mathematical formulas implemented in the library across open channel hydraulics, pressurized pipe networks, surface hydrology, hydraulic structures, groundwater mechanics, and sediment dynamics.

Strict SI Metric Standards Guarantee

Transparent Standard SI Metric Units

Dimensional inconsistencies represent a primary source of computational error in hydraulic engineering. HydroAj enforces strict, unambiguous SI metric units by default: meters ($m$), seconds ($s$), cubic meters per second ($m^3/s$), hours for storm duration, millimeters per hour ($mm/hr$) for rainfall intensity, and Pascals ($Pa$) for pressure. In your IDE (VS Code, PyCharm, or Jupyter), typing any function immediately displays the exact parameter units directly in the tooltip.

Python Usage Example (hydroaj.hydraulics) 
import hydroaj.hydraulics as hyd

# 1. Open Channel Flow: Compute discharge Q using Manning's equation
# Area = 12.5 m², Hydraulic Radius = 2.1 m, Bed Slope = 0.0015 m/m, Roughness n = 0.025 s/m^(1/3)
Q = hyd.manning_discharge(area=12.5, hydraulic_radius=2.1, slope=0.0015, roughness=0.025)
print(f"Manning Discharge Q: {Q:.3f} m³/s")

# 2. Parameter Inversion: Back-calculate required bed slope S0 given target Q = 35.0 m³/s
S0_req = hyd.manning_s0(discharge=35.0, roughness=0.025, area=12.5, hydraulic_radius=2.1)
print(f"Required Bed Slope S0: {S0_req:.6f} m/m")

# 3. Belanger Hydraulic Jump: Compute sequent post-jump depth y2 (y1 = 0.45 m, Fr1 = 4.8)
y2 = hyd.hydraulic_jump_sequent_depth(y1=0.45, froude1=4.8)
el = hyd.hydraulic_jump_energy_loss(y1=0.45, y2=y2)
print(f"Sequent Depth y2: {y2:.3f} m, Dissipated Energy Loss: {el:.3f} m")

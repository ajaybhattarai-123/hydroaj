HydroAj: Water Resources Engineering Reference Manual

Designed and Authored by Ajay Bhattarai (Civil Engineer, B.E. Civil Engineering)

HydroAj is an open-source, high-performance computational framework designed specifically for civil engineers, hydrologists, and environmental researchers. It combines a memory-safe, SIMD-accelerated Rust computational engine with an ergonomic, fully-vectorized Python API.

This manual provides the complete, unabridged reference for all 415 functions and mathematical equations in the library. Every routine is typeset in classical textbook format featuring vertical fractions, radicals, parameter definitions, and standardized SI units.

# 1. Manning Open Channel Flow Velocity & Discharge

# 2. Darcy-Weisbach Pipe Flow Friction Loss (L = 500 m, D = 0.30 m, V = 1.8 m/s, f = 0.018)

print(f"Darcy-Weisbach Friction Head Loss h_f: {h_f:.3f} m")

# 3. Bélanger Sequent Jump Depth (y1 = 0.45 m, Fr1 = 4.8)
y2 = hyd.hydraulic_jump_sequent_depth(y1=0.45, froude1=4.8)
el = hyd.hydraulic_jump_energy_loss(y1=0.45, y2=y2)
print(f"Sequent Depth y2: {y2:.3f} m | Energy Dissipation: {el:.3f} m")
